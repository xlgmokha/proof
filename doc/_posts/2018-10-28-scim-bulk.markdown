This endpoint adheres to [RFC-7644 Section 3.7](https://tools.ietf.org/html/rfc7644#section-3.7).

`POST /scim/v2/Bulk` performs up to 100 `POST`, `PUT`, `PATCH` and `DELETE` operations on `/Users` and
`/Groups` in a single request of at most 1 MB.

* Operations run in order and are independent. A failed operation is rolled back and reported with its
  status and an error `response`, and earlier operations remain applied.
* `failOnErrors` stops processing once that many operations have failed.
* A `POST` requires a unique `bulkId`. Later operations can refer to the created resource as
  `bulkId:<id>` in a `path` or in a string value of `data`. Unresolved references fail with `409`.
* The response lists the `status` and `location` of each operation.
